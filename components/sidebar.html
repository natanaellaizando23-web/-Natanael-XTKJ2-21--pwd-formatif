Dashboard Saya

Selamat datang di halaman sidebar saya. Halaman ini dibuat menggunakan CSS Flexbox untuk menyusun sidebar dan konten utama.

Sidebar berada di sebelah kiri dengan lebar 25%, sedangkan bagian konten utama berada di sebelah kanan dengan lebar 75%.

CSS digunakan untuk mengatur warna, ukuran, jarak, dan tampilan setiap bagian halaman agar terlihat lebih rapi.
